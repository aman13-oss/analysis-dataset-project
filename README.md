## 🔍 What I Practice

### 1. Data Understanding
- Loading datasets using Pandas.
- Understanding rows, columns, and data types.
- Exploring datasets using `head()`, `info()`, and `describe()`.
- Identifying important variables and understanding the dataset.

### 2. Data Cleaning
- Handling missing values.
- Removing duplicate records.
- Correcting data types.
- Detecting and handling inconsistent values.
- Identifying and analyzing outliers.
- Preparing datasets for further analysis.

### 3. Exploratory Data Analysis (EDA)
- Univariate analysis.
- Bivariate and multivariate analysis.
- Understanding distributions and relationships.
- Identifying patterns, trends, and anomalies.
- Using descriptive statistics to understand data.

### 4. Data Visualization
I practice creating different types of visualizations to understand and communicate data effectively.

- Bar Charts
- Line Charts
- Histograms
- Box Plots
- Scatter Plots
- Heatmaps
- Count Plots
- Distribution Plots

### 5. Insights & Interpretation
- Identifying important trends and patterns.
- Comparing categories and variables.
- Understanding relationships between features.
- Summarizing findings in simple language.
- Communicating insights using charts and observations.

## 📈 Learning Approach

I follow a practical, step-by-step approach:

1. Select a dataset and understand its business context.
2. Explore the data to identify quality issues.
3. Clean and preprocess the dataset.
4. Perform exploratory data analysis.
5. Create visualizations to understand trends and relationships.
6. Write observations and explain the insights.
7. Document the complete process in Jupyter Notebook.

I focus on understanding **why** a particular cleaning technique, analysis method, or visualization is used, not just writing code.
