# Titanic Data Analysis – Mini Project

## 📌 Project Overview

This is a **mini data analysis project based on the Titanic dataset**.

I created this project after learning the basic concepts of **NumPy, Pandas, Matplotlib, and Seaborn**. The main purpose of this project is to **practice and apply these four skills practically on a real-world dataset** rather than only learning them theoretically.

This project focuses on understanding the dataset, cleaning the data, performing basic analysis, and creating visualizations to find meaningful patterns.

## 🛠️ Technologies & Skills Used

* **NumPy** – Numerical operations and data handling
* **Pandas** – Data loading, cleaning, manipulation, and analysis
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization and relationship analysis
* **Jupyter Notebook** – Project development environment

## 📊 Dataset

The Titanic dataset contains information about passengers, including:

* Passenger ID
* Age
* Sex
* Passenger Class
* Fare
* Siblings/Spouses
* Parents/Children
* Embarkation Point
* Survival Status

## 🔍 Project Workflow

### 1. Data Understanding

* Loaded the Titanic dataset
* Checked the number of rows and columns
* Inspected column names and data types
* Checked missing values
* Checked duplicate rows
* Generated statistical summaries

### 2. Data Cleaning

* Handled missing values
* Removed unnecessary columns
* Renamed columns where required
* Created age groups
* Prepared the dataset for analysis

### 3. Data Analysis

Performed analysis to answer questions such as:

* What was the overall survival rate?
* How many passengers survived?
* What was the survival rate by gender?
* What was the survival rate by passenger class?
* What was the average age of passengers?
* What was the average fare?
* How are Age and Fare related?
* How does survival vary across gender and passenger class?

### 4. Data Visualization

Created different visualizations using Matplotlib and Seaborn:

* Bar Charts
* Histograms
* Pie Charts
* Scatter Plots
* Line Charts
* Heatmaps
* Pair Plots
